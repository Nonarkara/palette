01 / COLOUR

The relationships.

Sanzo Wada
1883–1967. The 348 relationships come from his colour research, including Haishoku Sōkan (1933–34), later republished as A Dictionary of Color Combinations. Publisher: Seigensha. Records: Art Platform Japan, publication history. No book scans or cover art are reproduced. Screen values are credited digital conversions, not printed ink.
Matt DesLauriers
dictionary-of-colour-combinations. MIT, copyright 2020. This is data/colors.json.
Dain M. Blodorn Kim
dblodorn/sanzo-wada. MIT, copyright 2024. The earlier compilation that the DesLauriers dataset corrected. His program is not copied here.

02 / AUTHORSHIP

What this site adds.

Dr Non Arkaraprasertkul: selection, unequal proportions, interface, search, role names, diagrams, and editorial readings. Temperature, energy, value, and suggested room are computed in the browser. They are not Wada’s words.

When a design rule and a human task disagree, measured contrast and the task win, and decoration loses. That conflict-order gate belongs to this project.

The same list is in CREDITS.md. Data terms are in THIRD_PARTY_NOTICES.md. Original code is MIT.

04 / MEASURE

The contrast sheet.

WCAG 2.2
Pass and fail use the W3C relative-luminance formula. Body text needs 4.5:1. Large text and non-text boundaries need 3:1. A ratio is not rounded up into a pass.
Machado, Oliveira, and Fernandes, 2009
Protanopia, deuteranopia, and tritanopia previews use their published severity-1.0 matrices in linear sRGB. A simulation, not a clinical test.
APCA
Myndex / Andrew Somers. Studied. The badge stays with WCAG 2.2. APCA code is not included.
Coolors
Copy one palette as CSS, Tailwind, and tokens. Proprietary. Interface not copied.
Adobe Color
Colour-vision preview and an accessibility note beside a palette. Proprietary. Interface not copied.
Huemint
A palette ready for an interface. Ours is the agent brief and role tokens. No new colours are generated.
Realtime Colors
Judge colours by living with them. Ours is the full-viewport plate, not a sample website.
Leonardo
Apache-2.0. Judge a palette by contrast targets. We measure Wada’s colours and do not copy the program.
Design Tokens Format
The JSON export uses $type, $value, and $description.
Tailwind
MIT, Tailwind Labs. The copy block follows v4 @theme and v3 theme.extend.colors. Tailwind is not bundled.
Mobbin, Dark Design, Saaspo, Curated
Mobbin, Dark Design, Saaspo, Curated. Proprietary galleries. What we took: one obvious task, a legible black instrument, and no marketing hero over the colour.
Open Design
Apache-2.0. A local handoff for a coding agent. Ours is the on-device copy actions. Their program is not installed.

05 / MAKING

Type and tools.

Archivo Narrow (Omnibus-Type), IBM Plex Sans Thai (IBM), Noto Sans SC (Google), and JetBrains Mono (JetBrains) are used under the SIL Open Font License. Files are requested from Google Fonts. That is a font host, not an analytics script. No other third-party script runs.

Tests use Playwright (Apache-2.0) and axe-core (MPL-2.0). Neither is part of the public page. GitHub Actions are pinned to commit SHAs. Dependabot watches npm and Actions.
