# Palette — walkthrough roadmap

## Now

- Fixed: normalize invalid plate hashes so the URL and visible plate cannot
  disagree.
- Fixed: enlarge the exhibition identity link to a 44 by 44 pixel minimum touch
  target.
- Fixed: separate the mobile identity from the vertical colour name.

## Next

- Run the Mama Rule with a consenting older, nontechnical first-time visitor on
  their own phone. Give one goal—“find a calm palette you would use”—and do not
  explain the symbols.
- If symbol recognition fails, test a single-use legend before changing the
  permanent instrument rail.
- Repeat on a throttled 4G connection and record font-loading behaviour.

## Later

- Test with colour-vision-deficiency simulation and a screen-reader user; the
  current grayscale study and textual labels are supports, not substitutes for
  those sessions.
- Consider remembering the last plate locally only if returning visitors ask
  for it; a URL already provides explicit, shareable memory.

## Never

- Do not add accounts, cloud search, analytics, a recommendation model, or an
  onboarding carousel without observed need. They would weaken the local,
  object-first room.
- Do not convert the exhibition into a card grid. The complete index may map the
  archive; it may not become the primary experience.
