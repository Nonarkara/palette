      Read the interval

      Sanzo Wada arranged 159 named colours into 348 combinations. The unit is the relationship. Red changes beside blue. Pale yellow changes again when it becomes the smallest part of a quartet.

      This edition makes each relationship large enough to inhabit. Search is a question, chance is a method, and the index is the map back out.

      阅读色彩之间的间距

      和田三造将159种具名色彩编排成348组配色。真正的单位不是单一颜色，而是颜色之间的关系。红色与蓝色并置后会改变；浅黄色在四色组合中占据最小面积时，也会承担新的作用。

      这个版本把每组关系放大到足以让人进入其中。搜索是一种提问，偶遇也是一种方法，而索引是离开展厅的地图。

      Dr Non's Digest

      可以把色彩理解为视觉的自然食欲。眼睛需要张力、停顿、温度和比例。和谐并不等于相同。好的配色会保留一点分歧，让画面继续呼吸。

      Digital values are conversions, not claims about exact printed ink.
